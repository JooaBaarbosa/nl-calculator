# nl-calculator Web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Página web React + TypeScript para o nl-calculator, servida pela própria API em `localhost:8000` e empacotada numa imagem Docker multi-stage que sobe com `docker compose up --build`.

**Architecture:** `web/` (Vite + React + TS) compila para `src/nl_calculator/static/`; `api.py` monta essa pasta em `/` depois das rotas da API (ou serve uma página de instrução se não houver build). O `Dockerfile` compila a página numa etapa Node e roda só Python na etapa final.

**Tech Stack:** React, TypeScript (strict), Vite, Vitest, React Testing Library, jsdom, ESLint (typescript-eslint, react-hooks), FastAPI `StaticFiles`, Docker multi-stage, Docker Compose, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-21-web-ui-design.md` (base: `docs/superpowers/specs/2026-10-19-nl-calculator-design.md`)

## Global Constraints

- Node 24 (LTS): `web/.nvmrc` = `24`; `package.json` `"engines": {"node": ">=24"}`.
- Nenhuma rota existente da API muda (`/calculate`, `/health`, `/docs`, `/openapi.json`).
- `vite build` grava em `src/nl_calculator/static/` (`emptyOutDir: true`); a pasta fica no `.gitignore`.
- Página e API na mesma origem; sem CORS.
- Interface em pt-BR; textos exatos da spec §3.1 e §3.3.
- Porta do Compose: `127.0.0.1:8000:8000`; `.env` com `required: false`; a chave nunca entra na imagem.
- Imagem final sem Node, sem `node_modules`, sem dependências de dev; processo sem root.
- `tsc --noEmit` com `strict: true`; ESLint limpo; cobertura do Vitest ≥ 90% (linhas).
- Python continua com `ruff`, `mypy --strict` e cobertura ≥ 90%.
- Comandos Python via `uv` (no Git Bash: `export PATH="$LOCALAPPDATA/Microsoft/WinGet/Packages/astral-sh.uv_Microsoft.Winget.Source_8wekyb3d8bbwe:$PATH"`).
- Todo commit termina com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Enter apertado de novo enquanto a resposta não chega** → só uma chamada à API. Teste na Task 4 (`ignores submit while loading`).
2. **Servidor cai no meio da sessão** (container parado) → alerta "Não foi possível falar com o servidor…" e o histórico continua lá. Teste na Task 4 (`keeps history after network error`).
3. **Mesma pergunta feita duas vezes** → o histórico não duplica; o item vai para o topo com o resultado novo. Teste na Task 4 (`moves repeated question to top of history`).
4. **Pergunta maior que 500 caracteres** → o campo não deixa digitar além de 500. Teste na Task 3 (`limits question to 500 characters`).
5. **Container subido sem `.env`** → página abre e `/calculate` responde `503 not_configured` (que vira a mensagem de configurar a chave). Verificação na Task 5 (smoke test) e no job `docker` da Task 6.
